# Azure-VM-Lab

## Overview
A practice lab where I deployed Windows and Linux virtual machines on Microsoft Azure and connected to them remotely.

## What I did
- Created Azure resource groups and virtual machines.
- Connected to the Windows VM using Remote Desktop Protocol (RDP).
- Connected to the Linux VM using Secure Shell (SSH).
- Practised basic Linux commands.
- Stopped and deallocated the Windows VM after practice.

## Linux commands practised
- cd — change directory
- ls — list files and folders
- pwd — display the current directory
- uname — display the kernel name
- hostname — display the machine's hostname

## Tools used
Microsoft Azure, Windows Server, Linux, RDP and SSH.

## What I learned
I practised deploying cloud machines, accessing them remotely and navigating a Linux environment through the terminal.
